# privilege-google-secrets

Demo-tier standalone app: Privilege Hubs brokering a Google Secret Manager credential to an AI agent. The agent holds only a Privilege agent access key; the mock Hubs gateway's policy allows the in-scope secret (custodian release) and refuses the out-of-scope ask — the refusal is the product. Every call renders in the shared GatewayTrace.

- Run: `./scripts/run.sh` (http://localhost:7826). Test: `npm test` (server = `node --test test/*.test.js`, a glob; web = vitest). Preflight: `npm run doctor`. Reset: `npm run reset`. Talk track: `npm run talk-track`. Content pack: `npm run content-pack`.
- Core: `server/src/hubs.js` (the mock gateway, agent key + grant, mock Google Secret Manager with three secrets, the three calls with their traces), `app.js` (the API: catalog, three gateway routes, why-better, runs/reset), `doctor.js` (also replays every scenario against the mock gateway), `story.js` (facts with measured/UNVERIFIED status, five scenarios).
- Rules that bite: loopback bind only; same-origin writes; zero outbound network (netguard) — there is NO live mode, `PGS_MODE_REAL=1` only enables the rule-19 Real switch; only `.invalid`/`.example`/`.privilege.example` hosts; one port, 7826; `POST /api/mode` is exactly `{ source: "mock"|"real" }` and switches at runtime (409 + reason when Real is not enabled); runs are per workspace (rule 13).
- Honesty rule: the wire and the agent-key model are measured (by other labs, 2026-11); the mock Google Secret Manager and the released credential are MOCK-issued and labelled (rule 4 exception). What the real product does with these shapes is UNVERIFIED and must stay labelled that way. Do not upgrade a claim without re-measuring.
- Trace semantics (do not weaken): every mock trace decision says `checked`; a real-shape trace may only say `observed`/`inferred` (assertTrace enforces it); a denied call's custodian decision is `skipped`, never a pass; no trace ever carries the raw agent key on a refusal, and the wrong-key value is never echoed.
- Web: `web/src/App.jsx` (four tabs, presenter, Reset, runtime Mock/Real toggle), `components/GatewayCards.jsx` (the three cards + released secret), `components/WhyBetter.jsx`, `gateway-trace/` (vendored, rule 25), `components/JsonPane.jsx` (vendored, rule 24). Colours from tokens only; no purple.
